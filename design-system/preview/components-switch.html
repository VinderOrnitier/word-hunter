Switch — settings toggle
Reload hint prompt to reload the page after starting a hunt
Show next word preview reveal the upcoming word in the celebration popup when Auto-Continue is on
32 × 18 track · 14 px thumb · pill radius. Off → --wh-surface-3 track, --wh-fg thumb. On → --wh-primary track, --wh-on-primary (almost-black) thumb so the contrast doubles as a "lit" affordance. role="switch" + aria-checked; the explicit "On"/"Off" label is included for readability at 12 px popup density (a bare track would be too small to scan).
Used in Settings for Reload hint and Show next word preview. The Auto-Continue toggle on the BottomActionBar is the same semantic switch but renders as an icon button instead of this control — pattern-equivalent, treatment-different on purpose (the action bar is icon-dense, Settings is form-dense).
