New: pending state. When the player clicks an uncaught slot but hasn't pressed Start a hunt yet, the slot wears a --wh-selected 1 px border + 4 px --wh-selected-soft glow. This signals "selected but not yet active" — a deliberate twin to the yellow active ring so the player can see they're holding a fresh pick, distinct from the live ActiveWord.

Uses the dedicated --wh-selected token (split out of the old overloaded --wh-hint) so a future hue change won't touch unrelated informational-blue surfaces.
