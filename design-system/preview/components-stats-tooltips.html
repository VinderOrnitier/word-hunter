Pattern: every trigger carries a data-tooltip="…" attribute and renders the tooltip with a ::after pseudo-element. Default state is opacity: 0; transform: translateY(4px); hover transitions to opacity: 1; translateY(0) over --wh-dur-fast. No JS, no aria-describedby plumbing, no portal — the tooltip lives in the same stacking context as its trigger.
Reference CSS
.thing { position: relative; cursor: default; }
.thing::after {
  content: attr(data-tooltip);
  position: absolute;
  bottom: calc(100% + 6px);
  left: 50%;
  transform: translateX(-50%) translateY(4px);
  padding: 4px 8px;
  background: var(--wh-surface-2);
  border: 1px solid var(--wh-border);
  border-radius: var(--wh-radius-2);
  box-shadow: var(--wh-shadow-2);
  font-size: 10px;
  color: var(--wh-fg);
  white-space: nowrap;
  pointer-events: none;
  opacity: 0;
  transition: opacity var(--wh-dur-fast),
              transform var(--wh-dur-fast);
}
.thing:hover::after {
  opacity: 1;
  transform: translateX(-50%) translateY(0);
}
Anchoring. Above-center is the default (used by the hint dot and the duration icon-header). Above-left for cells that hug the left edge (the truncated word column — mono font). Above-right when the trigger sits flush right (the link cell — sans font, page URL clipped with text-overflow: ellipsis on the tooltip itself so very long URLs don't blow out the popup). Proposed: consolidate the four ::after blocks under a single utility class: .wh-tooltip[data-tip-anchor="left|right|center"][data-tooltip]. One block, three anchors via attribute selector, zero per-component CSS to add the 5th tooltipped cell.
Proposed utility · single class for all tooltipped cells
.wh-tooltip {
  position: relative;
  cursor: default;
}
.wh-tooltip::after {
  content: attr(data-tooltip);
  position: absolute;
  bottom: calc(100% + 6px);
  padding: 4px 8px;
  background: var(--wh-surface-2);
  border: 1px solid var(--wh-border);
  border-radius: var(--wh-radius-2);
  box-shadow: var(--wh-shadow-2);
  font-family: var(--wh-font-sans);
  font-size: 10px;
  color: var(--wh-fg);
  white-space: nowrap;
  pointer-events: none;
  opacity: 0;
  transition: opacity var(--wh-dur-fast),
              transform var(--wh-dur-fast);
  z-index: 10;
}
.wh-tooltip[data-tip-anchor="center"]::after {
  left: 50%;
  transform: translateX(-50%) translateY(4px);
}
.wh-tooltip[data-tip-anchor="center"]:hover::after {
  transform: translateX(-50%) translateY(0);
}
.wh-tooltip[data-tip-anchor="left"]::after {
  left: 0;
  transform: translateY(4px);
}
.wh-tooltip[data-tip-anchor="right"]::after {
  right: 0;
  transform: translateY(4px);
}
.wh-tooltip[data-tip-anchor="left"]:hover::after,
.wh-tooltip[data-tip-anchor="right"]:hover::after {
  transform: translateY(0);
}
.wh-tooltip:hover::after {
  opacity: 1;
}

/* mono tooltips for word values */
.wh-tooltip--mono::after { font-family: var(--wh-font-mono); }
