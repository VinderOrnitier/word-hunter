--wh-list-animals is an alias of --wh-found (`var(--wh-found)`). The Animals list shares the success-mint hex by design — Animals never appear next to a Found surface in the same view, so the reuse never collides. Codified as an alias so any future hue split is a one-line change.

The old --wh-hint token meant "informational blue" in most uses and "selection state" in a few — split into --wh-info + --wh-selected. The alias keeps the codebase running while migration happens. --wh-info and --wh-selected resolve to the same hex today; promote to distinct hues only when a surface actually needs to show both at once.
