Recipe · drop transforms, keep opacity
@media (prefers-reduced-motion: reduce) {
  /* Drop scaling + translateY transitions everywhere, keep opacity for clarity. */
  .wh-progress-row__fill,
  .wh-progress-row__chevron { transition: none; }

  .hw-toast,
  .wh-reload-hint,
  .wh-ss__dropdown,
  .wh-settings__footer,
  .wh-action-footer {
    animation-name: wh-rm-fade-in;       /* opacity-only entry */
    animation-duration: var(--wh-dur-fast);
  }

  .hw-celebration__modal {
    animation: wh-rm-fade-in var(--wh-dur-base) var(--wh-ease-standard) both;
  }

  .wh-settings__range::-webkit-slider-thumb,
  .wh-settings__range::-moz-range-thumb { transition: none; }
}

@keyframes wh-rm-fade-in {
  from { opacity: 0 }
  to   { opacity: 1 }
}
Rule: when reduced-motion is on, drop every transform (translate, scale, rotate) and keep the opacity fade. Total entry duration shortens to --wh-dur-fast (120 ms) — enough to register a state change without animating motion.

Coverage status: ProgressRow ships its reduced-motion media query in popup.css today. The other surfaces are pending code-side adoption — listed above so a refactor can sweep them all in one pass instead of finding stragglers later.
