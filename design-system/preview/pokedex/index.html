type

Three families, three roles

Press Start 2P — labels stamped on the device (eyebrows, tab labels, button text). Never larger than 14 px.
VT323 — LCD output (the active word, counters, durations). The "displayed" font.
Space Grotesk — body / helper copy where pixel hurts legibility. The "explainer" font.

brand signature

Highlighter — Pokédex variant

The slate theme uses a thin yellow stripe under inline text. The Pokédex theme commits harder: the highlighted word becomes a yellow LED rectangle behind the text, with a pixel-art 1px charcoal outline (via inset shadow so layout doesn't shift) and a soft LED glow. The text inside flips to dark navy. The found-state swaps the rectangle to LED green.
