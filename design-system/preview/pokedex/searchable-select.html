SEARCHABLE SELECT

The last open control. Used wherever the option set is long enough to warrant typing to filter (e.g. picking a word from a large custom list). Pokedex variant: cream key-cap trigger with a pixel chevron, opening into a navy-framed LCD dropdown. The trigger and dropdown share a flattened seam so they read as one panel — same single-panel principle as slate, translated to the device.
