ICONOGRAPHY

Pokedex theme uses the Pixelarticons set by Gerrit Halfmann -- hand-crafted pixel-art icons on a strict 24x24 grid, MIT licensed. The free package ships 486+ icons; we wire it via Iconify so we never bundle anything we don't render.

SOURCE -- PIXELARTICONS Open source pixel-art icon set by Gerrit Halfmann. 24x24 author grid; every edge deliberate. MIT licensed. pixelarticons.com · github.com/halfmage/pixelarticons

the set · 16 roles

The 16 roles we use

A 1:1 mapping of slate's Lucide subset to the Pixelarticons set. Roles are stable; only the renderer changes per theme. Hover-name shows the Pixelarticons icon slug.

scale · 4 sizes

Size scale -- xl / lg / md / sm

Pixelarticons render sharpest at multiples of 24px. We use 72 / 48 / 24 / 16 in the popup -- 16px is borderline (icons start losing pixel crispness) so it's reserved for inline usage in body copy where the surrounding text already tolerates anti-aliasing.

color · currentColor

Recoloring via currentColor

All Pixelarticons fill with currentColor. Set the parent color to retone the entire glyph. The four semantic states the popup typically uses:

Red on trash / destructive · green on confirmed catch · yellow-deep on a lit star · lens-blue on info. Against a raspberry shell, icons flip to white via the surrounding color: var(--pdx-on-shell):

on LCD · navy on cyan

On an LCD surface

Inside an LCD well, icons read as the dark navy --pdx-lcd-ink. Scan lines + glare layer above the icon but stay subtle because both icons and scan-line spacing are grid-aligned.

usage · iconify-icon web component

How to use in the popup

One script include, one custom element, no per-icon import. The framework lazy-fetches icons on first render and caches them locally. 

<!-- once in the document head -->
<script src="https://code.iconify.design/iconify-icon/2.1.0/iconify-icon.min.js"></script>

<!-- anywhere in the markup -->
<iconify-icon icon="pixelarticons:search" style="font-size: 24px;"></iconify-icon>

<!-- recolor via parent -->
<span style="color: var(--pdx-led-yellow); font-size: 40px;">
  <iconify-icon icon="pixelarticons:star"></iconify-icon>
</span>

In the production extension we ship the Iconify offline plugin so icons load from a local bundle instead of the CDN, keeping the popup zero-dependency at runtime. The icon names below stay identical.
